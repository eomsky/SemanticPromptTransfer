## 2. LLM 검증 범위

`TransformersCpuGenerator`는 가짜 tokenizer/model을 주입한 단위 테스트로 CPU 호출 계약, 지연 로드, 생성 옵션을 검증했다. 실제 운영 스모크 환경에는 `transformers`, `torch`, 모델 파일이 없었으므로 `EvidenceTemplateGenerator`가 실행됐다. 이 폴백은 현재 근거의 인용과 수치만 사용하는 보수적 초안을 5개 항목에 생성했다.

따라서 이번 합격은 생성기 교체 구조와 실패 복구가 작동한다는 의미다. `Qwen/Qwen2.5-0.5B-Instruct`의 실제 CPU 지연시간·메모리·문장 품질은 모델을 배포한 환경에서 별도로 측정해야 한다.

## 3. HTTP 검증 범위

FastAPI 라우트와 HTML API 모드는 소스 컴파일, API 문자열, 패키지 리소스 포함으로 검증했다. 현재 런타임에는 선택 의존성 `fastapi`, `python-multipart`, `uvicorn`이 없어 실제 HTTP 서버 기동 테스트는 수행하지 않았다. 애플리케이션 서비스의 등록·조회·진행률·삭제 계약은 직접 실행했다.

## 4. 운영 판정

v0.21은 HTML에 맞는 애플리케이션 경계, 엄격한 문서 삭제, 다중 문서 단일 인덱스, 교체 가능한 CPU 생성기의 기준 구현으로 사용할 수 있다. 다만 임의 PDF/Excel 파일을 실제로 해석하는 전처리기는 `UploadProcessor` 외부 어댑터이며, 운영 배포 전 다음 연결이 필요하다.

- 실제 신용조사서 양식 매핑과 PDF 파서
- 인증·권한·악성파일 검사
- 객체 저장소와 운영 Vector DB
- 분산 작업 큐와 진행률 저장
- 실제 CPU 모델 배포 및 성능·품질 평가
- 공식 심사의견 Word 양식
