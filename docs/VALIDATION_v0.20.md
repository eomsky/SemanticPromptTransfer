## 2. 운영 스모크 범위

스모크 테스트는 축약된 가상 자료를 사용한다. 첨부파일 2건을 같은 인덱스에 UPSERT한 뒤 신용조사서 TIER 1·2와 검색 TIER 3을 조립하고, 여신유형 `운전자금` 및 산업분류 `C29`에 맞는 FEW SHOT을 선택했다. 마지막으로 한 문서를 삭제하고 다른 문서가 유지되는지 확인했다.

생성된 Word는 실제 LLM 심사의견 품질평가본이 아니라 항목 순서, 근거 ID, 진행률, 검증 게이트 및 문서 조립 계약의 스모크 산출물이다.

## 3. 패키지 판정

v0.20은 다음 용도로 사용할 수 있다.

- 운영 애플리케이션 연동을 위한 기준 구현
- 신용조사서 우선의 3단계 근거 구성
- 여러 첨부문서의 단일 case 인덱싱과 문서 단위 삭제
- 여신유형·산업분류별 FEW SHOT 선택
- 내부 LLM 및 공식 Word 양식 연동 전 개발·통합 테스트

다음 항목은 실제 은행 배포 전에 추가 검증해야 한다.

- 실제 신용조사서 양식과 항목 매핑 승인
- 실 FEW SHOT 익명화·승인·유효기간 관리
- HTML/API 인증, 권한, 악성파일 검사, Object Storage
- 분산 작업 큐, 재시도, 동시성, 장애복구
- Chroma 또는 승인 Vector DB의 부하·동시성·백업 검증
- 내부 LLM 어댑터와 생성 결과 업무 품질평가
- 은행별 항목 간 교차검증 규칙
- 공식 심사의견 Word 템플릿
- 보관기간·삭제·감사정책

`ChromaVectorStore`는 선택적 어댑터 코드가 포함됐지만 이번 환경에서는 Chroma 서버 연결시험을 수행하지 않았다. 기본 NPZ와 인메모리 어댑터의 계약 및 삭제 동작은 검증했다.
